# AI Report
This document reports my usage of artificial intelligence throughout the project development.  
in this project i used LLMs and Coding Agents to do various tasks.
---
## Section one: server development
### Domain and DB
**Model**: Gemini Flash v3.5  
I used ai in this section for advice only, e.g. what should be the data type for X in database schema.  
anything else inside domain layer (Entities and Repositories) was written from scratch by myself.
### Application layer
**Model**: Gemini Flash v3.5  
Although i didn't develop the application layer, i used ai to take advice about which fields of entities should be in DTOs.
### Infrastructure layer
**Model**: Gemini Flash v3.5  
This is potentially where i used ai the most.
since i was newbie to spring boot, i asked ai about the spring bean configuration.  
in Jdbc implementations inside infrastructure repository folder, i used ai to generate row mappers for entities as it was way too frustrating to check schema and entities and implement the row mapper at the same time.  
i also used ai to make gson builder use the same date and time format as java.  
finally for the API i took advice from ai for endpoint mapping.

## Section two: client development
### General
**Model**: Gemini Flash v3.5
I took advice from ai about how should i apply CLEAN architecture in client, mostly about naming conventions (e.g. i knew i had to make an interface that shows what can api give the ViewModels to later on do Dependency injection, but i didn't know what should i call it.)
### Infrastructure layer
**Model**: Gemini Flash v3.5
**Agenting tool**: Google Antigravity  
For some reason, when i tried to replicate what i have done with the gson builder on the server about date and time format i got runtime errors,
turns out that gson uses java SimpleDateFormat under the hood which generates a timezone specific data on the json object
thats why the client can't replicate the server's gson formatting for the date and time.
i used antigravity to fix this bug. it generated a TypeAdapter that did the job.

### Presentation layer
**Model**: Claude sonnet 4.6  
**Agenting tool**: Google Antigravity  
Since i had little to no knowledge about JavaFX (or any GUI Framework) i specified what i need to cluade so it generates a baseline for me to work on  
the code generated by claude was reviewed by myself to see if it obeyed our standards for application architecture and if it met our needs in code quality.  
further more any bugs related to ui was fixed with assistance of ai.  
later on i refactored the generated codes and fix any useless code.

**Model**: Gemini flash v3.6  
i took advice from this model about how i should make the client more memory efficient.
